常见问题

🤔 TeamFlow / 工厂台是干什么的？

一句话：你说想做什么 → AI 虚拟团队自动规划、写代码、跑测试 → 你点批准 → 项目里出现真实改动。

适合：有代码文件夹的开发者、独立开发者、小团队。不是 ChatGPT 聊天框，是会动你硬盘上文件的自动化产线。

你写一句话 → AI 规划 → AI 改代码 → 你 Approve → 文件夹里有 diff

第一次打开 App

你会看到一个欢迎弹窗，不用选 workflow，二选一就行：

图 2 · 首启弹窗 — 选「从零开始」或「已有代码」

选「从零开始」之后

  1. 填项目名（如 my-todo-app）→ 点「下一步」
  2. 一句话描述（如「本地优先 Todo 应用」）→ 下一步
  3. 确认技术栈（默认 React + Vite）→ 启动
  4. 看产线看板走 7 个阶段，等 Run 完成
✅ 成功：项目文件夹里出现骨架代码，Banner 提示「加第一个功能」

30 秒试用演示（推荐新手）

最快感受「AI 团队帮你干活」—— 不用自己想任务。

  1. 打开 工厂 页
  2. 点上方 chip 「试用演示」
  3. 系统自动填入任务并启动 Run（改 README 加「快速开始」）
  4. 看产线看板：规划 → 实现 → 自测 → 交付审批 → 审查
  5. 到审批时 → 右侧点 Approve
图 3 · Run 进行中 — 看板亮当前阶段，审批时右侧出 Approve

改现有代码（加功能 / 改文档）

  1. 顶栏选好工作区文件夹
  2. 工厂页大输入框写你想做的，例如：给登录页加验证码
  3. 看推荐产线显示「一人全栈」（不会看到 solo-dev 这种内部名）
  4. 下方预览条出现：预计时间、阶段数、可能影响哪些文件
  5. 点 启动 或按 ⌘/Ctrl + Enter
图 4 · 输入任务 → 预览条告诉你「会花多久、动哪些文件」→ 再点启动

修 bug

  1. 输入框直接粘贴报错或描述，如：修复登录 500 报错
  2. 产线看板自动切到「快速修复」（分析 → 修复 → 验证）
  3. 启动后 AI 先分析再改代码，比全栈流程更短

Run 暂停了 — 等人批准

到「交付审批」阶段，Run 会等你点头。你可以：

  • 工厂页顶部待办条看到「有 1 个 Run 等你批准」
  • 右侧 Context 面板点 Approve 继续，或 Reject 打回
💡 设置 → 通知 里可以选「只在最终交付批一次」，中间阶段自动过（信任质量门）。第一次用建议保持「每阶段都批」建立信任。

跑完了 — 绿色 Banner 告诉你下一步

Run 成功结束后，输入框上方会出现绿色卡片，不会把你晾在原地：

图 5 · 完成后 Banner — 点主按钮继续下一轮，不用重新想任务

不同任务类型，按钮文案不同：

  • 改完代码 →「加第一个功能」或「加相关测试」
  • 生成计划 →「开始执行计划」
  • 新建骨架 →「加第一个功能」

失败了 — 三个按钮救你

Run 失败（尤其测试/质量门没过）时，红色 Banner 出现：

图 6 · 质量门失败 — 再修一轮 / 自己开终端看 / 高级跳过（慎用）
  • AI 再修一轮 — 从失败阶段重新跑，让 AI 继续修
  • 打开终端 — 自己看日志、手动调试
  • 跳过此门·高级 — 确认你知道风险时，跳过这一次测试门

一般失败（非质量门）会显示「从 xxx 阶段重试」和「切换快速修复」。

没装 Claude Code CLI

工厂页会出现三步引导，帮你安装或配置路径：

  1. 看引导条 cli-setup-inline：检测 → 安装提示 → 配置路径
  2. 仍可以跑纯文字任务（写计划、审查报告），但不能自动改仓库文件
  3. 设置 → AI → 配好 API Key 后，文本类 stage 走 API 车道
App 不会假装能用 API 改文件 — 要自动改代码，必须配 Claude CLI（或手动在 Cursor 里合入）。

跟团队商量（工厂里 @ 角色）

  1. 工厂输入框下方点 「和团队商量」
  2. 选一个角色（如全栈工程师）
  3. 输入问题，发送 — 角色会回复建议
  4. 回复显示在 Console 里，可带着意见再启动 Run
图 7 · 工厂内快速问角色 — 不用切到团队页

多人讨论（架构评审 / 需求对齐）

  1. 侧边栏 团队 → 进入你的团队 → 团队聊天
  2. 切换到「讨论」模式
  3. 新建讨论 → 选会话 → 点「开始讨论」
  4. 选场景预设（架构评审 / 需求对齐 / 快速拍板），确认参与角色
  5. 多轮发言后点「总结讨论」→ 生成结论
  6. 结论卡片底部 →「按此启动 Run」一键带回工厂
图 8 · 讨论 Setup — 三个场景一键选角色

复制到 Cursor 继续改

  1. Run 完成后 → 工厂页切到 Deliverables（产物） 标签
  2. 点 「复制上下文」 或 Cursor 相关按钮
  3. 粘贴到 Cursor Chat，接着改 AI 没改完的部分

常见问题

「请选择工作区」

顶栏点文件夹图标，选你的项目目录。

「未绑定 CLI」

设置 → AI → 检测 Claude Code。或先跑纯文字任务。

Run 一直转圈不动

看底栏 WS 是否「已连接」。断线会显示「轮询中」。仍不行就重启 App。

看不到首启弹窗了

之前点过「稍后再说」。直接用工意图框三个 chip 即可。

⌘K 能干什么？

任意页面按 ⌘K（Windows 用 Ctrl+K），输入「工厂」快速跳转。

怎么少批几次？

设置 → 通知 → 审批策略 →「仅最终交付批一次」。
